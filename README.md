# 📁 File Organizer

A command-line file organizer built with Python.

The application scans a selected folder, classifies files by extension, and moves them into category folders such as Images, Documents, Audio, Python, Archives, and Other.

This project was created as part of my Python learning and software development portfolio.

---

## ✨ Features

- Scan and preview files before organizing them
- Organize files automatically by type
- Create category folders when needed
- Support multiple file extensions
- Prevent overwriting duplicate filenames
- Rename duplicate files automatically
- Validate folder paths
- Ask for confirmation before moving files
- Show a summary after organizing
- Count files by category
- Handle empty folders

---

## 📂 File Categories

The application currently organizes files into:

- **Images**
  - `.jpg`
  - `.jpeg`
  - `.png`

- **Documents**
  - `.pdf`
  - `.txt`

- **Audio**
  - `.mp3`
  - `.wav`

- **Python**
  - `.py`

- **Archives**
  - `.zip`
  - `.rar`

- **Other**
  - Any unsupported file extension
